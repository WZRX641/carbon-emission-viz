# 全球城市碳排放统计分析结论

**分析时间范围**：2019-01-01 至 2026-07-31
**数据来源**：Carbon Monitor Cities


## 1. 总体趋势

| 指标 | 数值 |
| :--- | :--- |
| 总记录数 | 623,025 条 |
| 覆盖城市数 | 45 个 |
| 覆盖行业数 | 5 个（Aviation、Ground Transport、Industry、Power、Residential） |
| 总排放量 | 19,160,237.24（单位沿用原始数据） |
| 日均排放均值 | 30.75（单位沿用原始数据） |
| 排放峰值日期 | 2020-11-29 |
| 峰值排放量 | 1,668.12 |

**结论**：峰值排放量（1,668.12）是日均值（30.75）的 **54.2 倍**，表明存在显著的极端排放事件，可能与突发事件或季节性集中排放有关。

*数据依据：`results/statistics_summary.csv`*

*数据依据：`results/city_ranking.csv`*


## 3. 时间规律

### 3.1 月份规律

| 月份 | 日均排放均值 | 月份 | 日均排放均值 |
| :---: | :--- | :---: | :--- |
| 1月 | 35.36 | 7月 | 28.59 |
| 2月 | 33.10 | 8月 | 28.63 |
| 3月 | 32.27 | 9月 | 28.69 |
| 4月 | 29.53 | 10月 | 28.85 |
| 5月 | 27.76 | 11月 | 32.31 |
| 6月 | 28.76 | 12月 | 35.28 |

**结论**：排放呈现 **“冬季高、夏季低”** 的规律。**1月排放最高（35.36），5月排放最低（27.76）**，最高月比最低月高出 **27.4%**，主要受北半球冬季供暖需求驱动。

*数据依据：`results/monthly_pattern.csv`*

### 3.2 周末 vs 工作日

| 类型 | 日均排放均值 |
| :--- | :--- |
| 工作日（周一至周五） | 31.08 |
| 周末（周六至周日） | 29.93 |

**结论**：周末日均排放比工作日低 **3.7%**，反映人类活动强度在周末有所减弱。

*数据依据：`results/weekend_pattern.csv`*

### 3.3 季节规律

| 季节 | 日均排放均值 |
| :--- | :--- |
| 春季（3-5月） | 29.86 |
| 夏季（6-8月） | 28.66 |
| 秋季（9-11月） | 29.93 |
| 冬季（12-2月） | **34.60** |

**结论**：**冬季排放最高（34.60），夏季最低（28.66）**，冬季比夏季高 **20.7%**，与北半球季节性和供暖需求高度相关。

*数据依据：`results/season_pattern.csv`*


## 4. 行业结构分析

| 行业 | 总排放量 | 占比 |
| :--- | :--- | :---: |
| **Industry（工业）** | 9,984,926.70 | **52.11%** |
| Power（电力） | 3,747,870.08 | 19.56% |
| Residential（住宅） | 2,958,728.18 | 15.44% |
| Ground Transport（地面交通） | 1,998,283.99 | 10.43% |
| Aviation（航空） | 470,428.30 | 2.46% |

**结论**：**工业（Industry）是最大的排放源，占比超过一半（52.11%）**。电力（19.56%）和住宅（15.44%）次之。航空排放占比最低（2.46%）。

*数据依据：`results/sector_structure.csv`*


## 5. 数据局限性说明

原始数据（Carbon Monitor Cities）仅包含以下字段：`city`、`date`、`sector`、`value`。

**缺少 `country`（国家）和人口规模字段**。根据任务书“没有字段不得虚构”的原则，本次分析 **未进行国家/洲际对比和城市规模分组**。如需补充，请数据提供方（A角色）提供外部映射表。
