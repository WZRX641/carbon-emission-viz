【提交前必读】组号 / 姓名占位符替换说明
========================================================

一、本包内需要替换占位符的位置（共 3 处）
--------------------------------------------------------
1. 期末报告.docx
   - 封面：课程 / 题目下已有信息，署名处为  【组号】 与 【姓名】
   - 第一章「团队分工与贡献」表格中 成员1~成员6 行为占位（六个任务包，每包一人）
   - 全文搜索“【”可定位所有待填占位符
   → 用 Word/WPS 打开后 Ctrl+H 全局替换：
       【组号】 → 你的组号（如：第 5 组）
       【姓名】/【学号】 → 各位成员自己的真实姓名与学号

2. 答辩PPT-全球城市碳排放分析与可视化.pptx
   - 封面页副标题区：小组成员名单处为 【组号】【姓名】
   → PowerPoint 打开后直接编辑对应文本框

3. 压缩包/项目说明中如出现“组号待填”，提交前一并确认

二、复现与运行（环境：Python 3.10+，pip install -r requirements.txt）
--------------------------------------------------------
   1) 全流程一键复现（清洗→统计→挖掘/预测，全自动）：
        python run_pipeline.py
      （本包已含清洗主数据 data/carbonmonitor_clean.csv，
        不依赖 28MB 原始文件即可直接运行 C 页面与 D 挖掘；
        若要重跑 A 清洗步骤，请到 Carbon Monitor Cities 官网
        https://cities.carbonmonitor.org/ 下载原始 CSV 放入 data/raw/）
   2) 单元测试与集成测试（31 项，全部通过）：
        python -m pytest -q
   3) 启动可视化页面（两个入口，内容一致，仅世界地图呈现方式不同）：
        streamlit run app.py             # 静态版：行政区区块图 + 渐变颜色条（推荐）
        streamlit run app_interactive.py # 交互版：plotly 圆点图 + 渐变颜色条
